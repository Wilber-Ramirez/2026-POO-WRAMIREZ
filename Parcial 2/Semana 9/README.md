Proyecto restaurante_app - Semana 9 (actualizado)

Estructura modular con modelos (Producto, Usuario), servicios (Restaurante) y main.py.
Se usan las estructuras de datos requeridas:
- Lista: para colecciones de productos y usuarios
- Tupla: para opciones del menú
- Diccionario: para mapear opciones del menú a funciones
- Conjunto: para mostrar categorías únicas
